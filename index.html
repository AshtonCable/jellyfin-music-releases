Which file do I need?

Android JellyfinMusic-x.y.z-release.apk — download on the phone and open it. Android 7.0 or newer.

macOS JellyfinMusic-x.y.z-macos.zip — unzip and move Jellyfin Music to Applications. Because the app is not notarised, macOS will refuse to open it the first time: see Opening on macOS below.

iPhone and iPad — install the web app: open the hosted web version in Safari, tap Share, then Add to Home Screen. No .ipa is published, and native iOS has not been tested on a real device (only the Mac simulator), so the web app is the supported route.

Web jellyfin-music-web.zip — unzip onto any HTTPS web host and open the URL. Works as an installable web app.

Opening on macOS

Apple only lets apps open without a warning when their developer pays for an Apple Developer account and notarises every build. Jellyfin Music is not notarised, so the first launch shows “Jellyfin Music” Not Opened or Apple could not verify…. You can approve it yourself, and you only have to do this once per version:

  1. Double-click the app once and dismiss the warning.
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Next to the message about Jellyfin Music, click Open Anyway, then confirm with your password or Touch ID.

On macOS 14 and earlier you can instead right-click the app and choose Open, then click Open in the dialog.
